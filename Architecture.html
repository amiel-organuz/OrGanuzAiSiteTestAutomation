OrGanuz AI Test Automation Architecture

Docker Compose runs a local FastAPI service, Swagger UI, Prometheus, and the Playwright test container. Test reports are written back to the host workspace.

Playwright Tests

tests service runs scripts/run-all-tests.sh.

  • TypeScript typecheck
  • UI project: chromium
  • API project: api

FastAPI

api:8000 serves health, OpenAPI, docs, and Prometheus metrics.

  • /health
  • /openapi.json
  • /metrics

Swagger UI

localhost:8080 loads the FastAPI OpenAPI schema.

Prometheus

localhost:9092 scrapes api:8000/metrics.

Reports

Playwright, Allure, JSON, JUnit, and blob reports are mounted back to the host.

Runtime Services

  • api: FastAPI app built from server/Dockerfile.
  • swagger: Swagger UI container using swaggerapi/swagger-ui.
  • prometheus: metrics server using server/prometheus.yml.

Test Flow

  • The API health check must pass before dependent services start.
  • The test container runs after API, Swagger, and Prometheus are available.
  • Reports are persisted through Docker bind mounts.

Key Commands

  • docker compose up --build api swagger prometheus
  • docker compose run --rm tests
  • npm run report
